# VAW ClipForge v0.5 — Review & Timeline Editor

## Open it
- Launch **VAW ClipForge** and click **Review / Timeline**, or double-click **VAW Review Studio** on Windows Desktop.
- If prompted, open a clip generated by v0.4 with its neighboring `v04-manifest.json` and `.srt` files.
- The first sample is `exports\videoplayback\videoplayback_v04_01_00243s_rev3.mp4`.

## Tools in the editor
1. **Scrub** the timeline or toggle **Silent Preview**. Playback displays video frames only, not audio.
2. **Caption editor**: select a subtitle row, correct its text or start/end timestamp (seconds), and click **Apply Line**. Add/delete segments if needed.
3. **Framing**: use the top-right horizontal source preview, click where you want the focus or adjust the Focus slider. Click **Pin Focus Keyframe** at the current video time.
4. Manual keyframes influence approximately 2 seconds around the selected timestamp. Elsewhere the original v0.4 auto-track positions remain active.
5. **Save Draft** stores editable changes as `<clip>.review.json`, without overwriting original media, captions or AI results.
6. **EXPORT EDITED MP4** renders a new version from the original horizontal source footage. The original output stays untouched.
7. The edited MP4 is accompanied by a new .SRT, .ASS, and .JSON file. You can edit again from the original clip.

## Limitations
- This is an original light-weight timeline review tool, not full CapCut/NLE functionality.
- Preview is silent; open the exported MP4 with Media Player to verify audio/caption synchronization.
- Changed subtitle text uses estimated per-word highlight timings across the caption phrase, not re-alignment by Whisper.
- A correction affects framing near its pin time. To maintain framing for a longer segment, add multiple keyframes.
- Scene cuts and automatic tracking come from the existing v0.4 metadata; no full video re-analysis is required to edit.
- Only v0.4 outputs listed in the manifest can currently be opened. The source video and subtitle SRT must still be present.
- Because source frame 640x360 is low resolution, no reframe algorithm can restore missing picture detail.
- Review captions before publishing; automatic transcripts can be inaccurate, especially with medical terminology.
