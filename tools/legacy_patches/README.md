# ClipForge legacy patch archive

These scripts are historical one-off migration and repair helpers from v0.x–v1.1 development. They are kept for traceability, not as part of the current runtime or installer.

- Do not run these scripts against the current checkout as a batch.
- Do not import them from the application.
- Prefer a normal code change, tests, and a reviewed Git commit for all current maintenance.
- If a recovery script is needed, inspect it and confirm its target version before execution.
